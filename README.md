# SVT Softbot Cloud Platform

## React Client

**Folder Structure**

| Path                     | Description                                                    |
| ------------------------ | -------------------------------------------------------------- |
| `/src/components`        | Reusable components                                            |
| `/src/icons`             | Icons                                                          |
| `/src/views`             | Components that are treated as views by the router             |
| `/src/views/{view_name}` | Individual view component and components specific to that view |
